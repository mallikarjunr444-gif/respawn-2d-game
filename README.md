# Event Horizon — Last Run to Earth (Godot 4 High-Graphics Edition)

A high-intensity 2D sci-fi survival platformer built with **Godot 4.7.2** featuring bloom, dynamic 2D lighting, volumetric particle systems, parallax space nebulae, responsive physics, and rich procedural audio synthesis.

Outrun the cosmic **Devourer**, solve reactor beam mirror matrix puzzles, wield devastating energy weapons, and survive across the cosmos to reach Earth.

## 🎮 Pilot Controls

| Action | Keyboard | Gamepad | Description |
|---|---|---|---|
| **Move** | `A` / `D` or `←` / `→` | Left Stick / D-Pad | Smooth acceleration & directional flipping |
| **Jump** | `Space` / `W` / `↑` | `A` / Cross | Variable jump height cut + coyote time |
| **Dash** | `Shift` | `B` / Circle | High-speed air & ground dash with invulnerability frames |
| **Energy Sword** | `J` / Left Click | `X` / Square | Melee swing that slices Voidlings and shatters barriers |
| **Plasma Blaster** | `K` / Right Click | `Y` / Triangle | Rapid-fire glowing energy bolts |
| **Gravity Lance** | Hold `K`, Release | Hold `Y`, Release | Piercing singularity shot that pulls enemies together |
| **Phase Shield** | `Q` | `LB` / L1 | 1.8-second energy bubble absorbing projectiles |
| **Interact** | `E` | `RB` / R1 | Access energy forge terminals and devices |
| **Retry** | `R` | Select / Back | Instant retry upon systems failure |
| **Menu / Pause** | `Esc` | Start | Return to menu / pause |

## 🌌 Worlds & Missions

1. **World 1 — The Fractured Moon:** Outrun the Devourer, calibrate the mirror reactor matrix to forge the Energy Sword, and slice through the ancient crystal barrier to reach the pod.
2. **World 2 — Aether-7:** Navigate high aerial plateaus and confront the **Aether Sentinel** guardian boss with rotating plasma shields.
3. **World 3 — Cinder Moon:** Volcanic sector with erupting magma vents and the Plasma Blaster terminal.
4. **World 4 — Cryos:** Low-friction glacial ice physics and Phase Shield energy tech.
5. **World 5 — Vortex Prime:** Face the colossal **Vortex Guardian** and wield the Gravity Lance.
6. **World 6 — Earth:** Atmospheric re-entry and a desperate final sprint to the extraction bunker.
7. **Infinite Frontier:** Endless procedural sector generation with increasing speed and rising Devourer aggression.

## 🎨 Visual & Audio Features
- **Godot Forward+ / Glow & HDR:** Multi-layer additive bloom, color grading, and saturation boost.
- **Dynamic 2D Lighting:** Visor headlamps, weapon muzzle flashes, and Devourer event horizon glow.
- **Particle Systems:** Plasma thruster plumes, meteor flame trails, crystal sparkles, and singularity accretion vortices.
- **Procedural Sci-Fi Synthesizer:** Real-time waveform audio synthesis for lasers, explosions, dashes, and alerts with zero external dependencies.
